      How it works
      
  
      Every message takes the cheap path first. Only uncertain ones pay for the LLM.
      
  
      
    
      1
      Small model
      MuRIL, a BERT-style encoder pre-trained on 17 Indian languages and English, with my own classification head over 60 intents. Fine-tuned on English only.
      
    
      2
      Calibrated confidence
      Temperature scaling (T = {{ "%.2f"|format(h.temperature) if h else "?" }}) makes the confidence honest: "90% sure" means right about 90% of the time.
      
    
      3
      Threshold
      Confidence {{ "%.2f"|format(h.threshold) if h else "t" }} or more: the small model answers. Below that, the message goes to the LLM. The threshold was picked on dev data, never on test data.
      
    
      4
      Safe fallback
      If the LLM fails, times out or hits the per-minute cap, the small model's answer is used, marked small_fallback. Nothing crashes.
