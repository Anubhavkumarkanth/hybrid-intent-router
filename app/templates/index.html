How it works

1

Small model first

A multilingual model fine-tuned on English only reads every message on a CPU in about 30 ms, in any of the four languages.

2

LLM only when unsure

If its calibrated confidence is below the threshold, the message goes to Gemini. If Gemini is down or busy, the small model's answer is kept.

3

Then it does the task

Weather, time, currency, maths, word meanings and jokes run live through free public APIs, and the reply is spoken back.

Built with PyTorch, ONNX Runtime, Flask and Gemini · Data: Amazon MASSIVE (CC BY 4.0) · Source code on GitHub
