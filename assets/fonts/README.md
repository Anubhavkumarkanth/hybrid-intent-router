# Fonts

Noto Sans Devanagari and Noto Sans Kannada (Regular, Bold), from
https://github.com/notofonts/notofonts.github.io (downloaded 2026-11-22).
License: SIL Open Font License 1.1 (see OFL.txt). Used to draw Hindi and Kannada text
in charts and video slides, because DejaVu has no glyphs for these scripts.
